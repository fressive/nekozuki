# Nekozuki

CTF Writeup Summarization & RAG System.

Distills CTF writeups into reusable technique files, then indexes them for semantic search.

## Setup

```bash
cp .env.example .env
# Edit .env with your API keys
uv sync
```

## Usage

```bash
# Check configuration and API connectivity
uv run nekozuki test
# Skip live API calls (offline checks only)
uv run nekozuki test --no-connectivity

# Summarize writeups from data.json
uv run nekozuki summarize

# Build embedding index
uv run nekozuki embed

# Query the RAG system
uv run nekozuki query "how to exploit blind SQL injection"

# Start the web UI
uv run nekozuki serve
```

## Project Structure

- `src/` — Python source code
- `output/` — Generated technique markdown files
- `data/` — Checkpoints, vectors, and intermediate artifacts
